# 课程 6：贪心与动态规划

本目录对应《人工智能程序设计与实践》第 6 次课，主题是“贪心与动态规划 × 用 AI 开发程序”。代码只使用 Python 标准库，重点覆盖课堂检查点和自主实践。

## 文件

- `lesson06_dp.py`：凑硬币、0-1 背包、回溯核验、预算 800 变体和必投项目约束。
- `results.json`：运行脚本生成的确定性结果。
- `progress.md`：进度报告，包含检查点、问题解决、自查、独立研究和 AI 使用记录。
- `research.md`：独立研究任务的展开说明。

## 运行

```bash
python lesson06_dp.py
```

程序会重新生成 `results.json`，并在标准输出中打印全部验收结果。

## 数据说明

指南表格给出了五件物品的重量，但“重要度”一列为空；正文同时规定了课堂检查点为 315，且最优组合是“睡袋、食物、水具”。本次实验把重要度明确设为：帐篷 90、炉具 70、睡袋 120、食物 115、水具 80。这样容量 1000 时唯一最优组合正好满足课堂检查点，容量 800 和必投约束也可以直接比较。
